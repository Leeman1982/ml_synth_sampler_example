# Branding: "O.C.P Delta City MK1 by ZOMBI SS"

The OLED UI (see [doc/oled_encoder_ui.md](oled_encoder_ui.md)) boots into a
splash screen reading **O.C.P / DELTA CITY / MK1 / by ZOMBI SS**, and every
screen title/heading elsewhere in the menu uses the same display font.

## Font

The lettering is the **"Knighthawks"** TrueType font, (c) 1999 by
**ck! [Freaky Fonts]** (http://www.freakyfonts.de). License terms from the
font's own readme: free for personal, non-commercial use; files may not be
modified or renamed; commercial use requires a small donation to the author
(ck@freakyfonts.de).

Because of that license, the `.ttf` file itself is **not** committed to this
repository - only the derived bitmaps needed to render the specific strings
used in the UI (see below). If you want to add new branded strings or your
own splash text, get your own copy of the font and regenerate.

## How the bitmaps are made

[`ui_font_knighthawks.h`](../ui_font_knighthawks.h) contains pre-rasterized
1bpp XBM bitmaps for a fixed, enumerable set of strings (every screen
title/heading used by [`ui.cpp`](../ui.cpp), plus the 4 splash lines) -
this isn't a full font, just the specific strings the UI needs. It's
generated by [`tools/gen_ui_titles.py`](../tools/gen_ui_titles.py) via
[freetype-py](https://pypi.org/project/freetype-py/):

```bash
pip install freetype-py
python3 tools/gen_ui_titles.py path/to/Knighth.ttf > ui_font_knighthawks.h
```

Titles are rendered at 9px; anything that comes out wider than 124px at that
size is skipped and falls back to the normal readable font automatically at
runtime (`UI_DrawTitle()` in `ui.cpp`) - the font is a wide/blocky display
face, so long strings ("Load WAV->AllKeys", "Delay Feedback", "Load SF2
Samples") aren't legible small enough to fit the 128px display anyway.

To add a new branded string: add it to `TITLE_STRINGS` (or `SPLASH_LINES`)
in `tools/gen_ui_titles.py`, regenerate, and commit the updated header.
